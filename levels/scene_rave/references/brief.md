# Scene Rave - brief (no reference image was supplied)

The user's prompt is an image-transformation prompt ("Hyper-chromatic Scenecore / Y2K emo-rave maximalism") written
for a 2D portrait. No image arrived, so this experiment level builds the prompt's ENVIRONMENT (section 4: neon
checkerboard floors, floating pixel hearts / stars / lightning bolts, holographic butterflies, cartoon skulls,
glittering diamonds, rainbow light trails, glitches, pixel sparkles, retro internet graphics, psychedelic spirals,
zebra print, sticker collages), its palette (section 3) and lighting (section 5). The character section (1) becomes
set dressing - bows, skulls, kandi beads, studs, striped columns, checker / zebra / leopard prints; no person's
likeness is invented and no real brand marks are used in the typography.

Palette: hot pink #FF1493, electric cyan #00F5FF, acid green #B6FF00, ultraviolet #9D00FF, jet black #080808,
candy purple and fluorescent orange accents.
